# Skill: Threads 自動投稿

毎朝6時にズーミンのThreadsアカウントへ投稿文を3本生成・自動投稿するスキル。
テーマ: 個人の気づき・生き方・誠実に稼ぐことへの想い。

## セットアップ（初回のみ）

1. Meta for Developers でアプリ作成 → Threads API を有効化
2. アクセストークンを取得（長期トークン推奨）
3. `.env` に追記:
   ```
   THREADS_ACCESS_TOKEN=your_token_here
   THREADS_USER_ID=your_user_id_here
   ```
4. launchd ジョブを登録:
   ```bash
   cp /Users/tsunezumi/Library/LaunchAgents/com.zoomin.threads-post.plist ~/Library/LaunchAgents/
   launchctl load ~/Library/LaunchAgents/com.zoomin.threads-post.plist
   ```

## 投稿スタイルガイド

- **文体:** 一人称（俺/僕）、カジュアル、飾らない
- **文量:** 100〜200文字程度。短く鋭く。
- **テーマ例:**
  - 誠実に働くことへの気づき
  - 在宅ワーカーとの関わりから学んだこと
  - お金・仕事・生き方への自分なりの考え
  - 採用・組織・人間性
  - 日々の小さな発見・違和感
- **NGワード:** 意識高い系フレーズ、キラキラ起業家感、マウント
- **トーン:** 正直、少し哲学的、親しみやすい

## 投稿生成ルール

- 3本はそれぞれ**テーマ・切り口を変える**
- 1本目: 仕事・ビジネス系の気づき（逆説型 or 結論先出し型を優先）
- 2本目: 人・関係性・生き方系（本音型 or 体験談型を優先）
- 3本目: 自由（問いかけ型 or 独り言）
- ハッシュタグは1〜2個まで（なくてもOK）
- **毎回、冒頭1行は「フック」を意識する**（下記参照）
- **毎回、最後の1行に行動喚起を入れる**（下記参照）

## バズ投稿パターン（毎日24時に自動更新）

> 最終更新: `scripts/threads-buzz-log.md` を参照

リサーチで判明したバズる型。毎回1本はこのどれかを使う。

**① 逆説型**（常識の逆を短く断言）
> 「売れたいなら、売ろうとするな」
> 「頑張るのをやめたら、仕事が面白くなった」

**② 本音・告白型**（「ぶっちゃけ言う」「正直に言うと〜」「本当は〜」で始める）
> 「正直に言うと、在宅ワーカーに救われてる日の方が多い」

**③ 結論先出し型**（1行目に答えを置いて引っ張る）
> 「誠実さは最強の戦略だと今は思ってる。理由は単純で——」

**④ 問いかけ型**（読者に考えさせる）
> 「今の働き方、5年後の自分に説明できる？」

**⑤ 体験談→気づき型**（「〜があって、気づいたんだけど」）
> 「在宅ワーカーと話してたら、俺の方が視野せまかった。」

**⑥ 数字×体験型**（具体数値で説得力）
> 「〇人採用して気づいたこと」「在宅ワーカー〇人と関わってわかったこと」

## フック（冒頭1行）テンプレ

- 「ぶっちゃけ言う。」
- 「〇年やってわかったこと。」
- 「これ、ずっと言えなかったんやけど。」
- 「〇〇って、みんな勘違いしてると思う。」
- 「正直に言うと、〜」

## 行動喚起（末尾1行）テンプレ

- 「これ、刺さった人いる？」
- 「同じ経験ある人、コメントで教えて。」
- 「どう思う？」
- 「これ共感したらリポストしてくれると嬉しい。」

## バズ投稿ナレッジの吸収（ズーミンが共有してくれた投稿を取り込む）

ズーミンが「これバズってた」「これ気になった」と他人の投稿を共有してきたとき、以下の流れで処理する：

1. **構造分析**：冒頭フック・型（逆説/本音/体験談/問いかけ/数字 等）・末尾行動喚起の3点を抽出
2. **ズーミン化変換**：その型を使ってズーミンのキャラ・確信・口語に翻訳した投稿案を2〜3本作る
3. **プール反映**：採用OKもらったら `scripts/posts-pool.md` の該当時間帯セクション（morning/noon/evening）に追記
4. **パターン台帳更新**：上記の「バズ投稿パターン」に新しい型として加える（既存型と被るなら例文を増補）

ズーミンが介入するのは「気になった投稿を貼る」「採用OK/NGを言う」の2回だけ。それ以外はこっちで処理する。

## ログ

`scripts/threads-post.log` に投稿内容と結果を記録。
`scripts/posts-used.log` に使用済み投稿のハッシュを記録（重複防止）。
