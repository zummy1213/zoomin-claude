# Skill: 検証班（AI生成物レビュー）

他のAI（Codex・ChatGPT・Gemini等）が生成したコード・文章・設計・提案などを、Claude が品質・正確性・整合性の観点でレビューするスキル。

## 起動方法

「検証して」「チェックして」「レビューして」+ 対象物を貼り付けて起動。

---

## 検証の種類

### 1. コード検証（Codex / Copilot 生成）
- **動作確認:** ロジックに矛盾・バグがないか
- **セキュリティ:** SQLインジェクション・XSS等の脆弱性
- **品質:** 可読性・命名・不要なコード
- **整合性:** 既存のコードベース・スタイルと合っているか
- **判定:** ✅ OK / ⚠️ 要修正 / ❌ NG

### 2. 文章・コンテンツ検証（ChatGPT 等）
- **事実確認:** 嘘・誇張・不正確な情報がないか
- **トーン:** ズーミン／Zoomin AIのブランドトーンと合っているか
- **論理:** 主張と根拠が一致しているか
- **NG表現:** キラキラ起業家感・意識高い系・「〜しましょう」等

### 3. 設計・提案検証（ChatGPT / Gemini 等）
- **実現可能性:** 現在のリソース・技術スタックで実装可能か
- **抜け漏れ:** 想定されるエッジケースや前提条件の確認
- **コスト感:** 費用・工数の妥当性
- **Zoomin文脈との整合:** ビジネス方針・優先事項と合っているか

---

## 出力フォーマット

```
## 検証結果

**対象:** [何を検証したか]
**判定:** ✅ OK / ⚠️ 要修正 / ❌ NG

### 問題点
- [具体的な指摘]

### 修正案
- [修正すべき箇所と改善案]

### 総評
[一言コメント]
```

---

## 判定基準

| 判定 | 基準 |
|------|------|
| ✅ OK | そのまま使える |
| ⚠️ 要修正 | 軽微な修正で使える |
| ❌ NG | 作り直しが必要 |

---

## 注意

- 「動くかどうか」だけでなく「Zoomインの文脈で正しいか」も見る
- Codexのコードはセキュリティと実装の整合性を特に重視
- 文章はズーミンのトーン・価値観に合っているかを最優先で確認
