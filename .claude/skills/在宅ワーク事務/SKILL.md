# Skill: Payment Statement（支払明細書作成）

常角G（ZoomIn）の在宅ワーカーへの支払明細書を作成するスキル。
毎月10日を目安に、前月分のデータをもとに1人1枚の明細書を生成する。

## 対象・ルール

- **対象グループ:** 紹介G = ZoomIn のワーカーのみ
- **スキップ条件:** 稼働時間数が 0 の人は作成しない
- **サポート料:** 全員一律 550円（税込）を総計から控除
- **対象月の自動判定:** 毎月10日に前月分を発行する。例: 4/10実行 → 対象月は202603月。ユーザーが対象月を明示した場合はそちらを優先する。
- **発行日:** 対象月の翌月20日（例: 3月分 → 2026/04/20）。作成タイミングに関わらず固定。
- **支払日:** 対象月の翌月25日。25日が土日祝の場合は翌営業日（`jpholiday` ライブラリで自動判定）。

---

## 入力フォーマット

ユーザーから以下の形式でデータを受け取る（コピペ or 表形式どちらでも可）。

```
対象月: YYYYMM月
発行日: YYYY/MM/DD

氏名, 時給, 稼働時間数, インセン1(税込), インセン2(税込), インセン2件数, 交通費(非課税), PCレンタル(税込), 先払(税込), その他(税込)
小本 美雪, 1300, 98, 0, 0, 0, 0, 0, 0, 0
小山 京志郎, 1300, 126, 30000, 0, 0, 0, 0, 0, 0
...
```

データが未提供の場合はユーザーに入力を促す。

---

## 計算ロジック

**インセンティブのルール:**
- インセン1: 達成者一律 30,000円（税込）
- インセン2: 1件 100円（税込）→ 件数 = インセン2(税込) ÷ 100

各ワーカーについて以下を計算する（floor = 小数切り捨て）。

```
報酬（税込）       = 時給 × 稼働時間数
報酬（税抜）       = floor(報酬(税込) / 1.1)
インセン1（税抜）  = floor(インセン1(税込) / 1.1)
インセン2（税抜）  = floor(インセン2(税込) / 1.1)
PCレンタル（税抜） = floor(PCレンタル(税込) / 1.1)  ← 表示はマイナス (x,xxx)

総計（税込）       = 報酬(税込) + インセン1(税込) + インセン2(税込)
                    + 交通費 - PCレンタル(税込) + その他(税込)
サポート料（税込） = 550  ← 常に控除、表示は (550)
先払（税込）       = 入力値  ← 控除、0の場合は 0 と表示
支給合計（税込）   = 総計 - 550 - 先払(税込)

課税対象額（税込） = 総計（税込）- 交通費（非課税）
税抜金額           = floor(課税対象額 / 1.1)
消費税             = 課税対象額 - 税抜金額
```

**備考欄の生成ルール（複数あれば " / " で連結）:**
- インセン1 > 0 → `インセン1 {金額}円`
- インセン2 > 0 → `インセン2 {金額}円（{件数}件）`
- PCレンタル > 0 → `PCレンタル -{金額}円`
- 先払 > 0 → `先払 -{金額}円`
- それ以外に備考があれば追記

## 出力後の確認

全員分の出力後、以下のサマリーを表示する:

```
### 作成完了

- 作成件数: {N}件
- スキップ（稼働0）: {名前リスト}
- 支給合計の総額: {全員の支給合計の合計}円
```
