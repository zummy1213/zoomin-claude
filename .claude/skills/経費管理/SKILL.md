# Skill: 経費管理（領収書仕分け）

領収書の写真を受け取り、内容を読み取って勘定科目を判定し、Excelに追記するスキル。

## 動線

1. iPhoneで領収書を撮影
2. claude.ai/code を Safari で開く
3. 写真をチャットに貼って「経費登録して」と送る

## 読み取り項目

| 項目 | 内容 |
|------|------|
| 日付 | 領収書記載の日付 |
| 店舗・支払先 | 店名または会社名 |
| 品目・内容 | 購入品・サービス内容 |
| 金額 | 税込合計金額 |
| 勘定科目 | 下記ルールで自動判定 |

## 勘定科目の判定ルール（税法上の経費科目）

| 内容 | 勘定科目 |
|------|----------|
| 電車・バス・タクシー・飛行機 | 旅費交通費 |
| ガソリン・駐車場・高速 | 旅費交通費 |
| 取引先との飲食・接待 | 交際費 |
| 社内・一人での飲食 | 福利厚生費 |
| 文房具・消耗品（10万円未満） | 消耗品費 |
| 書籍・雑誌・セミナー | 研修費 |
| 電話・インターネット | 通信費 |
| 郵便・宅配 | 通信費 |
| 広告・名刺・印刷 | 広告宣伝費 |
| PC・ソフト・機器（10万円未満） | 消耗品費 |
| 家賃・レンタルオフィス | 地代家賃 |
| 水道光熱費 | 水道光熱費 |
| その他判断できないもの | 雑費 |

## 実行手順（Claudeが行う操作）

1. 写真から上記項目を読み取る
2. 勘定科目を判定する
3. 読み取り内容をユーザーに確認表示する
4. 確認OKなら以下を実行:
```bash
cd ~/Desktop/claude\ code\ demo
python3 scripts/add_expense.py "日付" "店舗名" "品目" "金額" "勘定科目" "備考"
```
5. 完了を報告する

## 出力先

- Excel: `output/経費管理.xlsx`
- 画像: `output/領収書画像/` （圧縮保存）

## 注意

- 金額が読み取れない場合はユーザーに確認する
- 接待か社内飲食か判断できない場合は確認する
- 税込金額を記録する（税抜不要）
