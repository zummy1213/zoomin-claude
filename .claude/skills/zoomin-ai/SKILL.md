# Skill: Zoomin AI 開発・管理

Zoomin AI（株式会社Zoom In のAIコンサルサービス）の開発・管理を行うスキル。

## プロジェクト概要

- **正式名称:** Zoomin AI（「Zoom AI」と書かれていても同じプロジェクトとして扱う）
- **対象:** 日本の中小企業向けAIコンサルティング
- **方向性:** 業務に使える形に落とし込む・現場で定着させる
- **ポジション:** AIそのものを売るのではなく「導入・定着・運用保守」を売る

## ツール構成

- **Claude = 司令塔**（判断・実行・連携・文脈把握）
- **Codex = 実装部隊**（コード生成・技術作業・リファクタリング）
- **SuperWhisper = 音声入力**（オプション）

## 継続課金の設計思想

- スキルを「教える」のではなく「管理する」側に立つ
- クライアントの業務フローに深く入り込み属人化させる
- ITシステムの保守契約と同じ構造
- サーバー管理型にすることで「解約=使えなくなる」を実現

## 展開ロードマップ

- **フェーズ1（〜3社）:** ローカル構築で実績・ノウハウを貯める

## クライアントUI前提

- ChatGPT / Claude のAPI契約・キー管理はクライアント自身
- ログ・設定・履歴はZoomin AIサーバーに蓄積
- UIでこの前提を説明文としてベタ書きしない
- 明示的に求められたときだけ別途説明する

## 実装方針

- 単一HTMLファイル（inline CSS + JS）
- 外部依存はGoogle Fontsのみ
- フレームワーク・ビルドツールは使わない
- 新規ページは `Zoomin_AI/01_ランディングページ/` に追加
- 既存ページとのブランド一貫性を保つ
- UIは「入力 → AI処理 → 人が確認 → 保存/共有」の流れが伝わること
